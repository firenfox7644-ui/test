Liquidated Damages Calculation Illustration:
 
Below set of sample SLAs are considered for computing liquidated damage for a month:

S. No.	Measurement	Actual Achievement	Liquidated Damages Level
1.	Critical Applications	<99.5% and >= 99.0% 	5
2.	Tier 1 Applications availability	>= 99.9%	0
3.	Tier 2 Applications availability	<99.9% and >= 99.5% 	1
4.	Time to resolve – High Priority	100% within the defined target	0
5.	Time to resolve – Medium Priority	100% within the defined target	0
6.	Time to resolve – Low Priority	>=99% and <100% meeting the target	2
7.	Percentage of reopened tickets	<=2% tickets	0
8.	Submission of Root Cause Analysis (RCA) reports	<=3 Working days	0
9.	Percentage reduction of tickets	<8% to 5%	1

Considering the above table as SLA achievement for the first month (M1) of a quarter, liquidated damages percentage shall be obtained from the table provided in Paragraph 1 above, and multiplied with Services Fees paid and payable in the quarter of which M1 forms a part (X), which will be further added up to calculate the liquidated damages amount for M1, i.e., X*1.5/100 + X*0.1/100 + X*0.4/100 + X*0.1/100.

The liquidated damages for the second month (M2) of a quarter and for the third month (M3) shall be calculated similarly, at the end of quarter, in accordance with the table provided in Paragraph 1 above.
Adjustment to the Service Fees payable for M3, will be equal to:
(Service Fees payable for M3) – (sum of liquidated damages of each of M1, M2 and M3).
